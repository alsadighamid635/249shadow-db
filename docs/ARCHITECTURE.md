# Architecture - 249 SHADOW Database

## 1. Frontend

المجلد: frontend/

يحتوي على واجهة المستخدم:

- index.html: هيكل الصفحة.
- style.css: التصميم والألوان والتنسيق.
- app.js: إرسال البيانات إلى الخادم واستقبال النتيجة.

## 2. Admin

المجلد: admin/

يحتوي على لوحة الإدارة:

- index.html: صفحة تسجيل دخول الإدارة وعرض السجلات.
- admin.js: تسجيل الدخول وطلب السجلات وحذفها.

## 3. Backend

المجلد: backend/

- server.py: يستقبل طلبات HTTP ويتعامل مع الواجهات البرمجية.
- database.py: ينشئ اتصال SQLite ويهيئ جدول البيانات.

## 4. Database

المجلد: database/

الملف training.db هو قاعدة البيانات النشطة.

الجدول training_users يخزن:

- id: رقم السجل.
- username: اسم المستخدم التجريبي.
- demo_value: قيمة تدريبية نصية.
- created_at: وقت إنشاء السجل.

## 5. طريقة الاتصال

1. يفتح المستخدم واجهة frontend.
2. ترسل الواجهة البيانات إلى backend.
3. يتعامل backend مع database.py.
4. تُحفظ البيانات في SQLite.
5. تدخل الإدارة إلى admin لمشاهدة السجلات وإدارتها.

## 6. الملفات القديمة

المجلد archive/legacy يحتوي على app.py وقاعدة البيانات القديمة.
لا يستخدمهما التشغيل الحالي.
احتفظ بهما للمراجعة ولا تحذفهما قبل التأكد من عدم الحاجة إليهما.
