# 249 SHADOW Database

مشروع تعليمي محلي لإدارة البيانات باستخدام Python وSQLite.

## مكونات المشروع

- frontend: واجهة المستخدم.
- admin: لوحة الإدارة.
- backend: خادم HTTP ومنطق التطبيق.
- database: قاعدة بيانات SQLite النشطة.
- docs: شرح البنية وطريقة العمل.
- archive/legacy: ملفات النسخة القديمة.

## المتطلبات

- Python 3
- SQLite (مدمجة مع Python)

## تشغيل المشروع

من مجلد المشروع نفّذ:

    bash start.sh

سيطلب منك البرنامج كلمة مرور الإدارة.

ثم افتح المتصفح على:

    http://127.0.0.1:8767

ولوحة الإدارة:

    http://127.0.0.1:8767/admin/

## قاعدة البيانات

المسار النشط:

    database/training.db

جدول البيانات:

    training_users

## ملاحظات أمنية

- المشروع مخصص للتشغيل المحلي والتعلم.
- لا تنشر الخادم على الإنترنت بصورته الحالية.
- لا ترفع قواعد البيانات أو كلمات المرور إلى مستودع عام.
- جلسات الإدارة الحالية محفوظة في ذاكرة الخادم وتنتهي عند إعادة تشغيله.
